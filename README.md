# 📊 Sales Data Analysis & Dashboard (Excel)

## 💡 Project Overview
This project analyzes messy, unstructured sales data for an electronics and furniture store. The goal was to clean the raw data and build an interactive Excel dashboard to track key performance indicators (KPIs) such as total sales, top-performing cities, and category distributions.

## 🛠️ Tools & Techniques Used
* **Power Query:** 
  * Data cleaning and transformation.
  * Standardizing mixed date formats.
  * Splitting delimited text (City/Country, Product/Category).
  * Removing duplicates and handling null values.
* **Pivot Tables & Pivot Charts:** Aggregating data to extract insights.
* **Interactive Dashboard:** Built using Slicers for dynamic filtering.

## 📈 Key Insights
1. **Jeddah & Riyadh** are the top-performing cities in terms of total sales revenue.
2. **Electronics** dominate the sales, contributing to over 50% of the total revenue.
3. Sales trended highest during **Q1 (specifically February)**, indicating a seasonal peak.
